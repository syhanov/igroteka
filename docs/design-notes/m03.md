# Design Note M03: Управление количеством колонок в каталоге

## Статус

Принято.

## Контекст

В каталоге используются два раздела с разным количеством карточек: «Выбор редакции» и «Все игры». Для них необходимо определить, кто должен управлять количеством колонок — разработчик через медиазапросы или браузер автоматически через `auto-fit` и `minmax()`.

## Решение

Для раздела «Выбор редакции» количество колонок задаётся вручную с помощью медиазапросов.

В этом разделе всего четыре карточи, поэтому количество колонок имеет ограниченное число состояний. В зависимости от ширины экрана карточки располагаются либо в одну колонку, либо в две колоноки. Такое поведение заранее определено и не требует автоматического расчёта количества колонок браузером.

Для раздела «Все игры» количество колонок определяется браузером с помощью `auto-fit` и `minmax()`.

Для раздела «Все игры» количество колонок определяет браузер с помощью auto-fit и minmax(). Медиазапросы не задают количество колонок напрямую, а изменяют минимальную ширину карточки: 450px, 380px и 300px. На основании этого значения браузер автоматически определяет, сколько карточек помещается в строку.

## Рассмотренные альтернативы

### `auto-fit` и `minmax()` для «Выбора редакции»

Этот вариант был отклонён, поскольку для небольшого количества карточек не требуется полностью автоматическое изменение сетки. Количество карточек заранее известно, а необходимы только определённые состояния расположения.

### Медиазапросы для «Всех игр»

Этот вариант был отклонён, поскольку большое количество карточек потребовало бы задавать дополнительные состояния сетки для разных ширин экрана. Использование `auto-fit` и `minmax()` позволяет избежать большого количества медиазапросов и сделать сетку более гибкой.

## Когда выбранный подход может проиграть

Автоматическая сетка с `auto-fit` и `minmax()` для раздела «Все игры» может проиграть, если потребуется строго контролировать количество колонок на определённых ширинах экрана. В таком случае медиазапросы дадут более предсказуемый результат.

Ручное управление колонками через медиазапросы для «Выбора редакции» может проиграть, если количество карточек или требуемых состояний расположения значительно увеличится. Тогда автоматическая сетка станет более удобной.
