# Design Note M02: Выбор Grid и Flexbox для построения макета

## Статус

Принято.

## Контекст

При разработке главной страницы необходимо было выбрать способ построения сетки каталога игр и определить, где использовать CSS Grid, а где — Flexbox. Основными требованиями были одинаковый размер карточек, предсказуемое расположение элементов и простота поддержки макета.

## Решение

CSS Grid применён для блоков, где требуется выравнивание по двум осям, гибкая настройка элементов сетки и предсказуемое поведение при переполнении.

Для остальных элементов страницы используется Flexbox.

### Будущие возможности

Здесь требуется выравнивание по двум осям — Grid как раз даёт такую возможность, поэтому для этого элемента выбран именно он.

### Каталог игр

Grid позволяет задать структуру сетки, расстояния между карточками и минимальную ширину элементов. В моей реализации количество колонок определяется автоматически в зависимости от доступной ширины контейнера и минимального размера карточки.

### Все игры

Grid позволяет гибко настраивать расположение любого элемента внутри сетки — именно это было нужно для большой карточки.


### Остальные блоки

Flexbox используется для построения остальных частей страницы: навигации, интро, содержимого карточек, футера и других линейных контейнеров.

Эти элементы требуют выравнивания по одной оси, распределения свободного пространства и удобного позиционирования содержимого, для чего Flexbox подходит лучше всего.

## Рассмотренные альтернативы

### Flexbox с `flex-wrap`

Вариант с использованием Flexbox для каталога был отклонён.

При использовании `flex-wrap` размеры элементов зависят от доступного пространства строки. Если последняя строка содержит меньше карточек, они могут растягиваться или изменять свою ширину, из-за чего сетка выглядит менее аккуратно.

CSS Grid обеспечивает фиксированную структуру каталога и одинаковое расположение карточек независимо от количества элементов в последней строке.

## Последствия

### Положительные

- карточки каталога имеют одинаковые размеры;
- сетка остаётся стабильной при изменении количества элементов;
- проще изменять количество колонок на разных размерах экрана;
- Flexbox используется там, где требуется выравнивание элементов по одной оси, что делает код проще и понятнее.

### Отрицательные

- для понимания проекта необходимо знать и CSS Grid, и Flexbox;
- изменение структуры каталога требует изменения параметров Grid.
