# Design Note M04: Сборка каталога игр

## Статус

Принято.

## Контекст

Каталог игр формируется из массива данных. Для создания HTML-разметки карточек можно использовать `map()` и `join()` с одним присваиванием `innerHTML` либо цикл `for` с накоплением HTML-строки.

## Решение

Для сборки каталога выбран цикл `for`.

Этот вариант выбран потому, что на текущем этапе он для меня более читабельный и понятный. При использовании цикла хорошо видно последовательность действий: перебирается каждая игра, для неё создаётся разметка карточки, а затем результат добавляется в общую строку.

## Рассмотренная альтернатива

### `map()` + `join()`

Вариант с `map()` и `join()` был рассмотрен, но от него я отказался в пользу цикла `for`.

`map()` и `join()` позволяют сделать код компактнее и выполнить одну вставку готовой строки через `innerHTML`. Такой подход хорошо подходит для простого преобразования массива игр в HTML-разметку.

## Когда отклонённый вариант оказался бы лучше

`map()` + `join()` был бы удобнее, если бы задача заключалась только в простом преобразовании каждого элемента массива в HTML-разметку без дополнительной логики.

## Последствия

### Положительные

- код проще читать и понимать;
- последовательность формирования карточек хорошо видна;
- проще добавлять дополнительную логику внутрь цикла.

### Отрицательные

- код может быть более объёмным по сравнению с `map()` и `join()`;
- для простого преобразования массива `map()` и `join()` могут быть более компактным решением.
